보안 진단을 하다 보면 같은 장면을 자주 봅니다. 취약점은 찾았는데 고쳐지지 않고, 조치 가이드는 전달했는데 개발자에게는 와닿지 않는 장면이요. 이 블로그는 그 간극을 줄이려고 만들었습니다.

## 이곳에서 다룰 것

| 카테고리 | 내용 |
| --- | --- |
| 웹 취약점 진단 | 스캐너가 못 찾는 로직 취약점, 진단 절차, 언어별 조치 코드 |
| 모바일 앱 분석 | Frida를 이용한 동적 분석, 루팅 탐지와 무결성 검증의 원리 |
| 소스코드 보안 | SAST 운영과 오탐 판별, 시큐어 코딩 패턴 |
| 침투 훈련 | 사이버 킬체인 기반 시나리오 설계, 실습 인프라 구축 |
| 클라우드·컴플라이언스 | 클라우드 네이티브 환경의 보안 통제와 CSAP |
| 커리어·학습 | 자격증, 교육, 공모전 경험 |

## 글을 쓰는 원칙

- **원리 → 재현 → 진단 → 조치**까지 한 글 안에서 끝냅니다.
- 조치 방법은 실제로 적용할 수 있는 코드로 보여 줍니다.
- 가능하면 OWASP Top 10과 CWE 번호를 함께 적습니다.
- 모든 실습은 직접 구축한 환경이나 공개된 연습용 애플리케이션에서 진행합니다. 허가받지 않은 시스템에 따라 하지 마세요.
